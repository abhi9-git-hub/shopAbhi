# ShopAbhi frontend

This React frontend uses Create React App (`react-scripts`).

From this directory:

- `npm start` starts the development server at `http://localhost:3000`. API requests use the development proxy to `http://localhost:5000`.
- `npm run build` creates production files in `build/`. In production, the backend serves this directory.

Install all project dependencies from the repository root with `npm run install-all`.
